# Запуск SQULED Studio на dopscloud + GitHub

Только факты. Делай по порядку.

---

## 1. GitHub (один раз)

1. Создай новый репозиторий: имя **`squled`**, тип **Public**.
2. Залей в него **всё из этой папки** (`public`, `server`, `README.md`, `.gitignore`, `.env.example`, `deploy`).
   Кнопка «Add file» → «Upload files» → перетащи все папки → Commit.
3. Файл `.env` не заливай — его тут нет, и так надо (в нём пароли).
4. Адрес репозитория будет: `https://github.com/AStraleted/squled`

---

## 2. dopscloud → вкладка «Настройки»

1. **Runtime** → выбери **Node.js**
2. В поле команды запуска вставь это целиком.
   Поменяй только **ВАШ_ТОКЕН** на свой токен от inferhold:

```
cd ~ && rm -rf app && git clone https://github.com/AStraleted/squled.git app && cd app && printf 'API_TOKEN=ВАШ_ТОКЕН\nUPSTREAM_URL=https://api.inferhold.com\nHOST=0.0.0.0\nPORT=80\nDATA_DIR=../data\nADMIN_LOGIN=squledAD\nADMIN_PASSWORD=0806netU0806@\nALLOW_REGISTRATION=true\nDEFAULT_PLAN=free\nCONTACT_TELEGRAM=wesfw\n' > .env && node server/index.js
```

3. Нажми **«Сохранить запуск»**.
4. Запусти контейнер (Старт). Статус должен стать «Запущен».

> Данные (аккаунты, чаты) хранятся в `~/data` — вне папки `app`, поэтому
> перезапуск и обновление кода их не стирают.

---

## 3. Домен squled.ru (Reg.ru → DNS)

A-записи должны указывать на **IP контейнера dopscloud**:

```
A   @     <IP контейнера>
A   www   <IP контейнера>
```

IP контейнера смотри в dopscloud (Обзор / Настройки / доступы).
Если там уже стоит `95.163.244.138` и это и есть IP dopscloud — менять ничего не нужно.

---

## 4. Проверка

1. Открой `http://squled.ru`
2. Войди: **squledAD** / твой пароль
3. Сразу смени пароль: Настройки → Профиль
4. Вставь токен: он уже в команде запуска, но если что — там же

---

## Если не работает — что прислать мне

- **Вкладка «Логи»** в dopscloud — скопируй последние строки, пришли сюда.
- Ошибка **`EACCES` / про порт 80** → в команде запуска замени `PORT=80` на `PORT=8787`, сохрани, перезапусти, напиши мне (тогда домен настроим иначе).
- Ошибка **`git: not found`** → залей файлы через вкладку «Файлы» в папку `app`, а команду запуска поставь короткую:
  ```
  cd ~/app && node server/index.js
  ```
  и создай рядом файл `.env` с тем же содержимым, что в printf выше.
- Ошибка **`fetch is not defined`** → на хостинге старый Node, нужен Node 18+. Напиши мне.

## Что где лежит (коротко)

| Куда | Что | Зачем |
|---|---|---|
| **GitHub** (репо `squled`) | весь проект, **без** `.env` | код, откуда dopscloud его забирает |
| **dopscloud** (команда запуска) | токен + пароли в `printf` | секреты, их нет в публичном GitHub |
| **Reg.ru** (DNS) | A-записи на IP dopscloud | чтобы домен открывал сайт |
